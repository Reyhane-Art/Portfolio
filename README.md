# وب‌سایت نمونه‌کار ریحانه پیرزاده مقدم

این پوشه یک سایت کامل و ثابت (بدون نیاز به سرور) است. می‌توانید آن را **رایگان** روی GitHub Pages منتشر کنید و بعد از آن با **پنل مدیریت** (`/admin/`) متن‌ها، آثار و دسته‌بندی‌ها را عوض کنید.

```
index.html        خود سایت
content.json      همهٔ متن‌ها، آثار، دسته‌بندی‌ها، رزومه و اطلاعات تماس
img/              عکس‌ها (پنل خودش اضافه و حذف می‌کند)
admin/index.html  پنل مدیریت فارسی
fonts/            فونت دوران (برای پنل)
```

---

## ۱) انتشار رایگان روی GitHub Pages (یک‌بار، حدود ۱۵ دقیقه)

> از ایران برای ساخت حساب و تنظیمات گیت‌هاب ممکن است فیلترشکن لازم باشد. فیلترشکن را روشن کنید و در طول کار، کشور آن را عوض نکنید.

### گام ۱ — ساخت حساب
به [github.com](https://github.com) بروید و با ایمیل خودتان حساب بسازید (**Sign up**). نام کاربری را کوتاه و انگلیسی انتخاب کنید؛ بخشی از آدرس سایت می‌شود. ایمیل را تأیید کنید.

### گام ۲ — ساخت مخزن (Repository)
۱. بالا سمت راست روی **+** و بعد **New repository** بزنید.
۲. **Repository name**: مثلاً `portfolio`
۳. گزینهٔ **Public** را انتخاب کنید (برای Pages رایگان لازم است).
۴. چیز دیگری تیک نزنید و **Create repository** را بزنید.

### گام ۳ — بارگذاری فایل‌های سایت
۱. فایل zip را روی کامپیوتر باز (Extract) کنید.
۲. در صفحهٔ مخزن روی لینک **uploading an existing file** بزنید.
۳. **همهٔ محتویات** پوشهٔ باز‌شده (`index.html`، `content.json`، پوشه‌های `img`، `admin`، `fonts`، و فایل `README.md`) را بکشید و داخل صفحه رها کنید. (خود پوشهٔ اصلی را نکشید؛ محتویاتش را بکشید.)
۴. صبر کنید همهٔ فایل‌ها بالا بروند، پایین صفحه **Commit changes** را بزنید.

### گام ۴ — روشن کردن Pages
۱. در مخزن به **Settings ← Pages** بروید.
۲. زیر **Build and deployment**، در **Source** گزینهٔ **Deploy from a branch** را بگذارید.
۳. **Branch** را `main` و پوشه را `/ (root)` انتخاب و **Save** کنید.
۴. یکی دو دقیقه صبر کنید و صفحه را تازه کنید. آدرس سایت بالای همان صفحه ظاهر می‌شود:
   `https://نام‌کاربری.github.io/portfolio/`

سایت شما منتشر شد.

---

## ۲) ساخت توکن برای پنل مدیریت (یک‌بار)

پنل برای ذخیرهٔ تغییرات روی مخزن، یک «کلید دسترسی» (Token) لازم دارد. این کلید فقط به همین یک مخزن دسترسی می‌دهد.

۱. در گیت‌هاب بالا سمت راست روی عکس پروفایل ← **Settings**.
۲. پایین منوی چپ: **Developer settings ← Personal access tokens ← Fine-grained tokens**.
۳. **Generate new token** را بزنید.
۴. **Token name**: `portfolio-admin`
۵. **Expiration**: مثلاً ۳۶۵ روز (وقتی تمام شد، یک توکن تازه بسازید).
۶. **Repository access**: گزینهٔ **Only select repositories** را بزنید و فقط مخزن `portfolio` را انتخاب کنید.
۷. **Permissions ← Repository permissions ← Contents**: روی **Read and write** بگذارید. (چیز دیگری لازم نیست.)
۸. **Generate token** را بزنید و متن توکن را که با `github_pat_` شروع می‌شود **همان لحظه کپی کنید** (بعداً دیگر نشان داده نمی‌شود).

توکن مثل رمز عبور است؛ برای کسی نفرستید.

---

## ۳) استفاده از پنل مدیریت

۱. آدرس `https://نام‌کاربری.github.io/portfolio/admin/` را باز کنید.
۲. به تب **انتشار** بروید، بخش **اتصال به گیت‌هاب** را باز کنید و بنویسید:
   - نام کاربری گیت‌هاب
   - نام مخزن (`portfolio`)
   - شاخه: `main`
   - توکن
   - تیک «ذخیره روی همین دستگاه» را فقط روی کامپیوتر یا گوشی شخصی خودتان بزنید.
   - **آزمایش اتصال** را بزنید؛ باید «اتصال برقرار است» ببینید.
۳. حالا هر تغییری بدهید:
   - **متن‌های صفحه**: همهٔ نوشته‌ها، هم انگلیسی و هم فارسی.
   - **آثار**: افزودن اثر جدید با عکس، تعویض عکس، ویرایش مشخصات، تغییر ترتیب، حذف.
   - **دسته‌بندی‌ها**: افزودن، تغییر نام، ترتیب و حذف دسته‌ها.
   - **رزومه**، **تماس و عکس‌ها**.
۴. دکمهٔ **پیش‌نمایش** بالای صفحه سایت را با تغییرات شما نشان می‌دهد (هنوز منتشر نشده).
۵. وقتی راضی بودید: تب **انتشار ← انتشار تغییرات روی سایت**. یک تا دو دقیقه بعد روی سایت دیده می‌شود.

نکته‌ها:
- عکس‌ها خودکار مربع، کوچک و بهینه می‌شوند. فقط عکس اصلی را انتخاب کنید و در صورت نیاز با کشیدن و اسلایدر قاب را تنظیم کنید.
- تغییرات منتشرنشده روی همان مرورگر ذخیره می‌ماند و اگر صفحه بسته شود از دست نمی‌رود.
- اگر توکن ندارید یا مشکلی بود، «دانلود بستهٔ تغییرات» یک فایل zip می‌دهد؛ آن را باز کنید و محتوایش را در صفحهٔ مخزن با **Add file ← Upload files** بارگذاری کنید.
- «مجموعهٔ ویژه» (بخش تیره با گالری افقی) یک دستهٔ ثابت است. برای قرار دادن اثر در آن، هنگام افزودن اثر همین دسته را انتخاب کنید.

---

## اگر گیت‌هاب برای بعضی بازدیدکننده‌ها باز نشد

همین مخزن را می‌توان به سرویس‌های رایگان دیگر هم وصل کرد، مثلاً **Cloudflare Pages** یا **Netlify** (گزینهٔ Import from GitHub). پنل مدیریت همچنان روی همان مخزن تغییر می‌دهد و سایت خودکار به‌روز می‌شود. (آدرس پنل همان آدرس تازهٔ سایت + `/admin/` است.)

## تغییر دامنه
اگر دامنهٔ شخصی خریدید (مثلاً `reyhaneh.art`)، در **Settings ← Pages ← Custom domain** وارد کنید.
